# Grok Pane phone apps

Native WebView shells. Not a second computer. They open the pane URL (Tailscale or LAN).

| | |
| --- | --- |
| iOS | `mobile/ios/GrokPane.xcodeproj` — `make ios` or open in Xcode |
| Android | `mobile/android` — open in Android Studio |

First launch asks for the pane URL. The link control changes it later.

Set a Development Team in Xcode to run on a device. Android needs a local SDK.
